# 上线检查与回滚清单

本文档收敛为当前代码可执行的最小发布检查，适用于当前已实现的登录、投票、邀请码、管理员与 `dev-token` 相关链路。

## 上线前检查

- [ ] `JWT_SECRET` 与 `DB_PASSWORD` 已通过环境变量注入
- [ ] 必要时已配置 `REDIS_PASSWORD`
- [ ] 后端测试通过：`mvn test`
- [ ] 后端可打包：`mvn -DskipTests package`
- [ ] 前端检查通过：`npm run check`
- [ ] 前端 lint 通过：`npm run lint`
- [ ] 前端构建通过：`npm run build`
- [ ] 手工冒烟通过：
  - 注册
  - 登录
  - 未登录写接口返回 `401`
  - 创建投票成功
  - 投票成功
  - 邀请码加入/退出链路可用
  - 管理员概览与用户管理链路可用

## 发布步骤

1. 发布后端
2. 校验 `POST /api/auth/login`
3. 校验 `GET /api/votes`
4. 校验受保护写接口的 `401` 语义
5. 校验邀请码相关接口与管理员接口
6. 发布前端
7. 校验首页、登录页、投票详情页与管理/创建中心

## 回滚原则

### 代码回滚

- 回退到上一版稳定构建产物
- 重新启动后端与前端
- 重新验证登录与投票主链路

### 配置回滚

- 恢复上一版环境变量或部署配置
- 重启服务
- 验证数据库连接与登录链路

## 当前不纳入本文档的内容

以下内容在当前仓库中没有稳定实现，因此不作为发布门禁：

- Kubernetes 专项发布流程
- 独立 RBAC 体系
- refresh token 轮换与撤销
