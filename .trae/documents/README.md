# Vote 文档索引

本目录只保留当前仍作为项目说明使用的正式文档。凡是报告、历史草稿、自动生成说明或一次性审计材料，统一归档到 `docs/`，不再作为当前实现说明的权威来源。

## 使用原则

- 以源码为准，文档用于解释当前实现
- 如文档与代码冲突，以当前代码行为为准，并应优先修正文档
- `docs/` 中的材料用于归档和审计，不作为功能承诺

## 当前不作为正式说明的内容

以下内容不再代表当前代码能力，已归类为历史或待重写材料：

- 管理后台操作手册
- RBAC 权限矩阵
- 旧版 PRD 与超前规划文档
- 后端代码自动生成说明

如果这些内容仍需保留，应放入 `docs/` 并明确标记为归档材料。

## 当前实现边界

当前项目已实现：

- 注册与登录
- JWT 鉴权
- 投票列表、详情、结果
- 创建投票
- 邀请码加入、退出与管理
- 提交投票
- 添加自定义选项
- 管理员概览与用户管理
- 管理员二次确认令牌
- `dev/local` 环境下的 `dev-token`
- 统一异常处理

当前项目未实现：

- 默认管理员引导改密
- refresh token 轮换与撤销
- 独立 RBAC 体系
- 自动生成后端全景文档的持续维护流程
